Privacy Policy

Effective date: October 23, 2026

1. Information We Collect

This application operates as a demonstration of self-play reinforcement learning algorithms. We do not require account registration, and we do not collect personal identification information such as names, email addresses, or phone numbers.

When you play a game, move coordinates and board states are transmitted to the server to compute the agent response. These move sequences are processed in memory and are not stored with user identifiers.

2. Technical Log Data

Standard web server logs may temporarily capture IP addresses, HTTP request paths, browser user-agent headers, and error codes for operational diagnostics and system security. These logs are routinely discarded.

3. Local Storage

This website may store user preferences (such as selected difficulty or preferred player color) in your browser local storage. This data remains on your device and is not transmitted to third parties.

4. Contact

For questions regarding this policy, contact the project maintainer through the repository issue tracker.
